# Website nhà phát triển – cmih1206.github.io

Thư mục này là trang web cho app Deutsch Prep: trang giới thiệu, Chính sách quyền riêng tư và `app-ads.txt`.

## Đăng lên GitHub Pages (5 phút)
1. Đăng nhập GitHub bằng tài khoản **Cmih1206** → **New repository**.
2. Tên repo phải đúng: **`cmih1206.github.io`** (chữ thường), chọn **Public** → Create.
3. Bấm **uploading an existing file**, kéo thả TẤT CẢ file trong thư mục này (kể cả `.nojekyll`) → **Commit changes**.
4. Vào **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` / `(root)` → Save.
5. Sau 1–2 phút kiểm tra:
   - https://cmih1206.github.io
   - https://cmih1206.github.io/privacy.html
   - https://cmih1206.github.io/app-ads.txt  (phải hiện đúng 1 dòng `google.com, pub-1100353976827889, DIRECT, f08c47fec0942fa0`)

## Khai báo trên Google Play Console
- *Store presence → Store settings → Website*: `https://cmih1206.github.io`
- *Policy → App content → Privacy policy*: `https://cmih1206.github.io/privacy.html`
- *App content → Ads*: chọn **Yes, my app contains ads**.

Sau khi app lên Play, vào AdMob → Apps → app-ads.txt → **Check for updates** (AdMob có thể mất tới 24 giờ để xác minh).
